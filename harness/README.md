# harness/ — Hatch detection harness

A static page that measures every signal a site can use to tell a phone from a desktop and compares
it with the values a persona promises. It runs in three places with the same files:

- **headless Firefox 158** on the VPS (`make headless` → `tool/headless/run.mjs`), served by
  `tool/headless/server.mjs` on two ports (page + cross-origin frames);
- **the phone**, copied into the APK as `assets/selfcheck/` and served by the in-app `LocalHttpServer`;
- **a browser tab** for manual poking: `node tool/headless/server.mjs` then open
  `http://127.0.0.1:8765/index.html?persona=win-firefox__us-east&env=device`.

Only relative URLs are used (`./echo`, `./report`, `./personas/<id>.json`, `./frame.html`,
`./worker.js`, `./vendor/detectors.bundle.js`) so it works under any base path. The host page may set
`window.__hatchCrossOrigin` (a URL prefix of a second origin that serves `frame.html`); otherwise the
cross-origin signal is SKIPPED.

## Query parameters

`?persona=<identityId>__<regionId>` selects `personas/<id>.json` (generated by
`tool/headless/gen-expectations.mjs` from `/personas/*.json`; `persona=none` = no expectations, every
value-comparison becomes INFO). `&env=headless|device` (default: `headless` when `navigator.webdriver`,
else `device`). Device-scoped signals are SKIPPED in headless.

## Output

On completion the page sets `window.__hatchResult` (schema v1 below), dispatches `hatch:done`,
POSTs the JSON to `./report`, and renders the table. Buttons: Copy JSON, Copy table, Send report, Re-run.
Tapping the box fills `interactive.pointerEvents` (hard) and `interactive.pointerType` (soft) and re-dispatches `hatch:done`.

```
{ schema: 1, harnessVersion, persona, env, url, crossOrigin, startedAt, finishedAt, durationMs,
  harness: { version, probes[], libraryManifest },
  expected: <personas/<id>.json or null>,
  observed: { ua, touch, media, css, layout, screen, intl, geo, webgl, misc, contexts, server, interactive, libraries[] },
  signals: [ { id, group, tier: "hard"|"soft", scope: "both"|"device", desc,
               status: "PASS"|"FAIL"|"SKIPPED"|"INFO", expected, actual, note? } ],
  libraries: [ { name, version, mobile, expectedMobile?, status, detail, note? } ],
  summary: { overall: "PASS"|"FAIL", pass, fail, skipped, info, hardFail[], softFail[], deviceSkipped[],
             libraryFail[], libraryTotal, libraryPass } }
```

`summary.overall === "PASS"` iff no hard FAIL, no library FAIL and (on device) no device-scoped SKIPPED.
The signal table (ids, tiers, scopes, checks) is `evaluate.js` → `SIGNALS`; it is pure and unit-tested
(`node --test test/*.test.mjs`).

## Files

| File | Role |
|---|---|
| `index.html`, `harness.js` | page + orchestration (ES modules) |
| `evaluate.js` | compare logic, result schema, text table (shared with node tests and the runner) |
| `probes/*.js` | `ua`, `touch`, `media` (JS matchMedia + CSS-level), `screen` (+layout), `intl`, `geo`, `webgl`, `misc`, `contexts`, `server`, `interactive`, `libraries` |
| `breakpoints.css` | `@media` rules that flip `--hit` on probe elements (engine-level, shim-proof) |
| `frame.html`, `worker.js` | iframe / worker snapshot sources for the context-consistency probes |
| `personas/*.json` | generated expectations (`npm run gen-expectations`, checked by `make lint`) |
| `vendor/entry.js` → `vendor/detectors.bundle.js` + `vendor/MANIFEST.json` | exact-version detector libraries bundled with esbuild (`npm run vendor-build`, verified by `npm run vendor-check`) |
| `test/*.test.mjs` | node tests (evaluate logic with desktop / phone / partial-spoof fixtures; Gecko Accept-Language algorithm) |
