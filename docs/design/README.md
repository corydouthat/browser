# Design source

`hatch-screens.dc.html` is the "Signal" design for Hatch, exported from Cory's Claude Design project
(file `Hatch Screens.dc.html`, imported 2026-10-21). It is the source of truth for colours, type, sizes and
every screen state; open it in a browser that can reach `support.js` from the Claude Design project, or read
it as HTML: each phone mockup is a `data-screen-label` block, and the palettes, role mapping and sample data
are in the `<script data-dc-script>` at the end.

`hatch-icon-gray.svg` is the launcher artwork on the design's graphite background (`#3A3A3F`); the artwork
itself is unchanged from `docs/icon-preview.svg` (Openclipart #354586, CC0).
